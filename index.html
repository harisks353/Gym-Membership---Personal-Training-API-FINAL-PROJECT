Project Overview

This FastAPI application manages gym registrations, calculates fees based on activity rates, and secures staff-only records using HTTP Basic Authentication.

API Endpoints

Method Endpoint Description
POST /register-membership Registers a member and calculates total fees. Data is validated using Pydantic.
GET /staff-portal/members Retrieves the full list of members. Requires Staff Authentication.
