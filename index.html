Elite Gym Management System

Developer: Haris Mohammed (Student ID: 70454)

Project Description

This is a FastAPI-based REST API for managing gym memberships. It uses Pydantic for data validation and HTTP Basic Auth for staff security.

API Endpoints

Method Endpoint Description
POST /register-membership Register a new member and calculate total training fees.
GET /staff-portal/members Private archive of all gym members (Requires Staff Login).
